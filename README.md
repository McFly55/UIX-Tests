# UIX-Tests
## UI-Spielwiese

Eine spielerische Sammlung over-engineerter, stark animierter UI/UX-Elemente (Lautstärkeregler, Passwort-Prüfung, Helligkeitsregler, An/Aus-Schalter, Drehregler, Preis-Spanne, Zahlselektion, Datumsselektierer, Farbwähler, Uhrzeit-Wähler, Sterne-Bewertung, segmentierte Steuerung, Stimmungswähler, Checkboxen, Like-Button, Fortschritts-Ring, Akkordeon, Konfetti & magnetischer Knopf).

Keine echte Funktion dahinter — reines Design, Animation und Ästhetik.

Zum Ausprobieren einfach `index.html` im Browser öffnen (alles lokal, keine Abhängigkeiten außer Google Fonts).

- `index.html` — Struktur & Widgets
- `styles.css` — komplettes Styling inkl. Dark/Light-Theme
- `app.js` — gesamte Interaktionslogik (Vanilla JS)
